Audience: jury for a project presentation and live demo.
Objective: show that MyOwnIDE is a working browser-based coding environment with clear practical value for competitive programming and learning.

Narrative arc:
1. Introduce the product and its positioning.
2. Show the user pain point.
3. Explain the core functionality.
4. Show the technical implementation and deployment maturity.
5. Walk through a live demo script.
6. Close with value, uniqueness, and roadmap.

Slide list:
1. Cover: project identity and one-line pitch.
2. Problem: why another IDE matters.
3. Solution: key features and user flow.
4. Architecture: frontend, execution engine, AI, and deployment.
5. Demo: what to show live in 60-90 seconds.
6. Impact and roadmap: why the project deserves attention.

Visual system:
- Dark product-forward palette.
- Real project screenshots as evidence.
- Large readable headings.
- Minimal, jury-friendly cards.

Editability plan:
- All visible text authored as editable slide text.
- Screenshots used as supporting plates only.
- Speaker notes used as prompt for the spoken delivery.
